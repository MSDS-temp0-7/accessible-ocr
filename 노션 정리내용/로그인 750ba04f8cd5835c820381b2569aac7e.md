# 로그인

카테고리: 인증
설명: 사용자 로그인을 수행하고 토큰을 발급합니다.
Method: POST
URL: /auth/login
param: email, password
기타: 자원봉사자의 경우 본인인증 절차 포함됨.
사용자: 공통

### Request

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| email | 로그인 이메일 | String |  | N | user@example.com |
| password | 로그인 비밀번호 | String |  | N | password123! |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `accessToken` | API 접근용 JWT 토큰 | `String` |  | N | `"eyJhbG..."` |
| `refreshToken` | 토큰 갱신용 JWT 토큰 | `String` |  | N | `"dGhpcy..."` |
| `user` | 유저 기본 정보 객체 | `Object` |  | N | `{"userId":...}` |
| `user.userId` | 사용자 고유 ID | `String` |  | N | `"usr_123"` |
| `user.role` | 사용자 권한 등급 | `String` | READER, INSPECTOR, VOLUNTEER | N | `"READER"` |

**Example**

```jsx
{
  "accessToken": "eyJhbG...",
  "refreshToken": "dGhpcy...",
  "user": {
    "userId": "usr_123",
    "role": "READER"
  }
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 정상 로그인 및 토큰 발급 완료 |
| 400 | {errorCode: AUTH_04, message: 이메일 또는 비밀번호가 일치하지 않습니다.} |
