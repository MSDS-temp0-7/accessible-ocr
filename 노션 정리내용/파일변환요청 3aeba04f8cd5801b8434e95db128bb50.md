# 파일변환요청

카테고리: 산출물 내보내기
설명: 완료된 문서를 DAISY 표준 패키지 또는 HWP로 변환하도록 요청합니다
Method: POST
URL: /documents/{id}/export
param: format (DAISY, HWP)
사용자: 검수자

### Request

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `format` | 변환할 표준 산출물 포맷 | `String` | DAISY, HWP | N | `"DAISY"` |

### **Query parameter**

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| `id` | 변환할 문서의 고유 ID (Path) | `String` |  | N | `"doc_998877"` |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `status` | 변환 작업 진행 상태 | `String` | PROCESSING, DONE | N | `"PROCESSING"` |
| `message` | 상태 안내 메시지 | `String` |  | N | `"파일 변환이 시작되었습니다."` |

**Example**

```jsx
{
  "status": "PROCESSING",
  "message": "파일 변환이 시작되었습니다. 완료 시 알림이 발송됩니다."
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 정상 변환 요청 완료 (비동기 처리 시작) |
| 400 | {errorCode: REQ_04, message: 지원하지 않는 출력 포맷입니다.} |
| 401 | {errorCode: AUTH_01, message: 로그인이 필요합니다.} |
| 403 | {errorCode: AUTH_03, message: 기관 검수자 권한이 필요합니다.} |
