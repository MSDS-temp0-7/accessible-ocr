# 문서 삭제

카테고리: 문서 관리
설명: 더 이상 필요 없는 문서나 업로드된 파일을 삭제합니다.
Method: DELETE
URL: /documents/{id}
param: id (Path)
사용자: 공통

### **Query parameter**

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `id` | 삭제할 문서의 고유 ID (Path) | `String` |  | N | `"doc_998877"` |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `success` | 삭제 성공 여부 | `Boolean` |  | N | `true` |
| `message` | 결과 안내 메시지 | `String` |  | N | `"문서가 성공적으로 삭제되었습니다."` |

**Example**

```jsx
{
  "success": true,
  "message": "문서가 성공적으로 삭제되었습니다."
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 정상 삭제 완료 |
| 401 | {errorCode: AUTH_01, message: 로그인이 필요합니다.} |
| 403 | {errorCode: AUTH_03, message: 해당 문서를 삭제할 권한이 없습니다.} |
| 404 | {errorCode: DOC_04, message: 요청하신 문서를 찾을 수 없습니다.} |
