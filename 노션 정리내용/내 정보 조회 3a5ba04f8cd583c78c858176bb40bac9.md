# 내 정보 조회

카테고리: 유저
설명: 현재 로그인한 유저의 프로필 및 권한(Role)을 조회합니다.
Method: GET
URL: /users/me
param: -
사용자: 공통

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| userId | 사용자 고유 ID | `String` |  | N | "usr_778899" |
| name | 사용자 이름(또는 닉네임) | `String` |  | N | "홍길동" |
| role | 부여된 권한 등급 | `String` | READER, INSPECTOR, VOLUNTEER | N | "READER" |
| email | 가입 이메일 주소 | `String` |  | N | "user@example.com" |
| isVerified | 자원봉사자 본인인증 여부 | `Boolean` |  | Y | true |

**Example**

```jsx
{
  "userId": "usr_778899",
  "name": "홍길동",
  "role": "READER",
  "email": "user@example.com",
  "isVerified": true
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 정상 조회 완료 |
| 401 | {errorCode: AUTH_01, message: 토큰이 존재하지 않거나 만료되었습니다.} |
