# 전체 문서 검색

카테고리: 검색
설명: 기관에 업로드된 스캔 문서 중 특정 상태나 제목의 문서를 검색합니다.
Method: GET
URL: /search/documents
param: keyword, status
사용자: 검수자

### Query parameter

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| `keyword` | 검색어 (문서 제목 등) | `String` |  | Y | `"수학 정석"` |
| `status` | 문서의 현재 처리 상태 | `String` | `PROCESSING`, `AI_DRAFT`, `DONE` | Y | `"AI_DRAFT"` |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `documents` | 검색된 문서 목록 배열 | `Array` |  | N | `[{...}]` |
| `documents[].documentId` | 문서 고유 ID | `String` |  | N | `"doc_12345"` |
| `documents[].title` | 문서 제목 | `String` |  | N | `"수학 정석.pdf"` |
| `documents[].status` | 문서 상태 | `String` |  | N | `"AI_DRAFT"` |
| `documents[].createdAt` | 업로드 일시 | `String` | ISO 8601 포맷 | N | `"2026-07-31T10:00:00Z"` |

**Example**

```jsx
{
  "documents": [
    {
      "documentId": "doc_12345",
      "title": "수학 정석.pdf",
      "status": "AI_DRAFT",
      "createdAt": "2026-07-31T10:00:00Z"
    }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 정상 조회 완료 |
| 401 | {"errorCode": "AUTH_01", "message": "토큰이 존재하지 않거나 만료되었습니다."} |
| 403 | {"errorCode": "AUTH_03", "message": "검수자 권한이 없습니다."} |
