# 내 문서함 조회

카테고리: 유저
설명: 개인이 업로드한 문서 목록과 AI 초안/검수완료 상태를 봅니다 (Step R2, R3). 
Method: GET
URL: /users/me/documents
param: status (완료/초안)
사용자: 유저

### **Query parameter**

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| `status` | 필터링할 문서 상태 | `String` | `AI_DRAFT`(초안), `DONE`(완료) | Y | `"AI_DRAFT"` |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `documents` | 개인이 업로드한 문서 배열 | `Array` | 업로드 최신순 정렬 | N | `[{...}]` |
| `documents[].documentId` | 문서 고유 ID | `String` |  | N | `"doc_112233"` |
| `documents[].title` | 문서 제목 | `String` |  | N | `"2026년도 전공서적.pdf"` |
| `documents[].status` | 문서 상태 (Step R2, R3) | `String` | PROCESSING, AI_DRAFT, DONE | N | `"AI_DRAFT"` |
| `documents[].uploadedAt` | 업로드 일시 | `String` | ISO 8601 포맷 | N | `"2026-07-31T15:30:00Z"` |

**Example**

```jsx
{
  "documents": [
    {
      "documentId": "doc_112233",
      "title": "2026년도 전공서적.pdf",
      "status": "AI_DRAFT",
      "uploadedAt": "2026-07-31T15:30:00Z"
    }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 정상 조회 완료 |
| 401 | {errorCode: AUTH_01, message: 토큰이 만료되었습니다.} |
