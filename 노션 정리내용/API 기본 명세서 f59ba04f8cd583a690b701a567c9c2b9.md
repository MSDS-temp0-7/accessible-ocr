# API 기본 명세서

[엔드포인트](%EC%97%94%EB%93%9C%ED%8F%AC%EC%9D%B8%ED%8A%B8%20bb3ba04f8cd582eaaacf01ba6862715a.csv)

## 1. 작업 모드 선택 API

- **설명**: 사용자가 리더/검수자 모드 중 어떤 것으로 진입할지 서버에 알리고 라우팅 경로를 받습니다 (F13)[cite: 1].
- **Method & URL**: `POST /api/v1/auth/mode`

## Request (프론트엔드가 백엔드로 보내는 데이터)

### 1. Headers

| Key | Value | Required |
| --- | --- | --- |
| `Authorization` | `Bearer <Token>` | O |
| `Content-Type` | `application/json` | O |

### 2. Body (전송할 JSON)

```json
{
  "mode": "READER"
  // "READER"(리더), "INSPECTOR"(기관 검수자), "VOLUNTEER"(자원봉사자) 중 하나
}
```

## Response (백엔드가 프론트엔드로 돌려주는 데이터)

### 성공 (200 OK)

```jsx
{
  "isAuthorized": true,
  "redirectPath": "/reader/dashboard"
}
```

### 실패 (403 Forbidden - 미인증 자원봉사자 접근 시

```jsx
{
  "errorCode": "AUTH_002",
  "message": "본인인증이 완료된 자원봉사자만 접근할 수 있습니다."
}
```

## 2. 자료 업로드 및 AI 초안 생성 API

- **설명**: PDF나 스캔 이미지를 업로드하고 AI 인식 파이프라인 처리를 요청합니다 (F14)[cite: 1].
- **Method & URL**: `POST /api/v1/documents/upload`

## Request

### 1. Headers

| Key | Value | Required |
| --- | --- | --- |
| `Authorization` | `Bearer <Token>` | O |
| `Content-Type` | `multipart/form-data` | O |

### 2. Body (Form-Data)

| Key | Type | Description | Required |
| --- | --- | --- | --- |
| `file` | `File` | 업로드할 문서 파일 (.pdf, .jpg 등) | O |

---

## Response

### 성공 (201 Created)

```json
{
  "documentId": "doc_998877",
  "fileName": "science_book.pdf",
  "status": "PROCESSING",
  "message": "AI 초안이 생성 중입니다."
}
```

## 3. 문서 블록 데이터 조회 API (노션 상세 페이지용)

- **설명**: 특정 페이지의 AI 인식 텍스트, 신뢰도, 원본 이미지 대비 좌표값을 조회합니다 (F6, F7, F8)[cite: 1].
- **Method & URL**: `GET /api/v1/documents/{documentId}/pages/{page}/blocks`

## Request

### 1. Path Variables

| Name | Type | Description | Required |
| --- | --- | --- | --- |
| `documentId` | `String` | 조회할 문서의 고유 ID | O |
| `page` | `Integer` | 조회할 페이지 번호 | O |

---
