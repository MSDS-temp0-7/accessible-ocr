# 문서 상태 조회

카테고리: 문서 관리
설명: 현재 AI 변환 진행 상태나 검수 완료 여부를 확인합니다.
Method: GET
URL: /documents/{id}/status
param: id (Path)
사용자: 공통

### **Query parameter**

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `id` | 상태를 조회할 문서의 고유 ID (Path) | `String` |  | N | `"doc_998877"` |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `documentId` | 문서 고유 ID | `String` |  | N | `"doc_998877"` |
| `status` | 문서의 현재 진행 상태 | `String` | PROCESSING, AI_DRAFT, DONE | N | `"AI_DRAFT"` |
| `progress` | AI 변환 또는 검수 진행률 | `Integer` | 0 ~ 100 (%) | N | `100` |

**Example**

```jsx
{
  "documentId": "doc_998877",
  "status": "AI_DRAFT",
  "progress": 100
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 정상 상태 조회 완료 |
| 401 | {errorCode: AUTH_01, message: 로그인이 필요합니다.} |
| 404 | {errorCode: DOC_04, message: 요청하신 문서를 찾을 수 없습니다.} |
