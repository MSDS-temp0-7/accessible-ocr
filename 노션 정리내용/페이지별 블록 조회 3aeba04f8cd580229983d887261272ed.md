# 페이지별 블록 조회

카테고리: 편집 및 검수
설명: 특정 페이지의 원본 이미지 매핑 좌표와 텍스트, 신뢰도 점수를 조회합니다 (F6, F7)
Method: GET
URL: /documents/{id}/pages/{page}/blocks
param: id, page
사용자: 검수자

### **Query parameter**

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `id` | 조회할 문서의 고유 ID (Path) | `String` |  | N | `"doc_998877"` |
| `page` | 조회할 페이지 번호 (Path) | `Integer` |  | N | `1` |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `documentId` | 문서 고유 ID | `String` |  | N | `doc_998877` |
| `pageNumber` | 응답된 페이지 번호 | `Integer` |  | N | `1` |
| `annotations` | 페이지 내 인식된 객체(블록) 배열 | `Array` |  | N | `[{...}]` |
| `annotations[].blockId` | 블록 고유 ID | `String` |  | N | `blk_001` |
| `annotations[].type` | 비정형 데이터 분류 타입 | `String` | TEXT, MATH, TABLE 등 | N | `TEXT` |
| `annotations[].content` | 인식된 텍스트 및 수식(LaTeX) 결과 | `String` |  | Y | `시각장애인을 위한...` |
| `annotations[].confidence` | AI 신뢰도 점수 | `Float` | 0.0 ~ 1.0 사이 값 | N | `0.98` |
| `annotations[].bbox` | 이미지 내 영역 좌표 | `Object` | 백분율(%) 기준 | N | `{x:10.5, y:20.1...}` |

**Example**

```jsx
{
  "documentId": "doc_998877",
  "pageNumber": 1,
  "annotations": [
    {
      "blockId": "blk_001",
      "type": "TEXT",
      "content": "시각장애인을 위한 통합 도구",
      "confidence": 0.98,
      "bbox": {
        "x": 10.5, 
        "y": 20.1, 
        "w": 50.0, 
        "h": 5.0
      }
    }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 정상 조회 완료 |
| 401 | {errorCode: AUTH_01, message: 로그인이 필요합니다.} |
| 403 | {errorCode: AUTH_03, message: 검수자 권한이 없습니다.} |
| 404 | {errorCode: DOC_04, message: 요청하신 문서를 찾을 수 없습니다.} |
