# 블록내용수정

카테고리: 편집 및 검수
설명: 검수자가 오탈자나 수식 등을 수정한 결과를 서버에 반영합니다 (F6)
Method: PATCH
URL: /documents/{id}/blocks/{blockId}
param: correctedContent

사용자: 검수자

### Request

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `correctedContent` | 검수자가 수정한 텍스트 또는 수식 데이터 | `String` |  | N | `"수정된 텍스트 내용입니다."` |

### **Query parameter**

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| `id` | 문서 고유 ID (Path) | `String` |  | N | `"doc_998877"` |
| `blockId` | 수정할 블록의 고유 ID (Path) | `String` |  | N | `"blk_001"` |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `blockId` | 수정이 반영된 블록 ID | `String` |  | N | `"blk_001"` |
| `status` | 처리 결과 상태 | `String` | UPDATED | N | `"UPDATED"` |
| `updatedAt` | 수정이 반영된 일시 | `String` | ISO 8601 포맷 | N | `"2026-07-31T18:30:00Z"` |

**Example**

```jsx
{
  "blockId": "blk_001",
  "status": "UPDATED",
  "updatedAt": "2026-07-31T18:30:00Z"
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 정상 수정 완료 |
| 400 | {errorCode: REQ_01, message: 잘못된 데이터 형식입니다.} |
| 401 | {errorCode: AUTH_01, message: 로그인이 필요합니다.} |
| 404 | {errorCode: DOC_04, message: 요청하신 블록을 찾을 수 없습니다.} |
