# 재검토 필요 큐 검색

카테고리: 검색
설명: 체류 시간이 미달되어 다시 확인해야 하는 구간 큐를 검색합니다 (F9).  
Method: GET
URL: /search/blocks/review-needed
param: documentId
사용자: 검수자

### **Query parameter**

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `documentId` | 검색할 대상 문서 ID | `String` |  | N | `"doc_12345"` |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `queue` | 재검토 필요 구간 배열 (F9 큐) | `Array` |  | N | `[{...}]` |
| `queue[].blockId` | 블록 고유 ID | `String` |  | N | `blk_05` |
| `queue[].pageNumber` | 해당 블록이 위치한 페이지 | `Integer` |  | N | `15` |
| `queue[].focusDurationMs` | 측정된 체류 시간(밀리초) | `Integer` | 기준 미달된 시간 기록 | N | `500` |
| `queue[].bbox` | 영역 좌표 | `Object` | 백분율(%) | N | `{x:10.5...}` |
| `queue[].content` | 블록 내용 | `String` |  | N | `빠르게 지나친 문장` |

**Example**

```jsx
{
  "queue": [
    {
      "blockId": "blk_05",
      "pageNumber": 15,
      "focusDurationMs": 500,
      "bbox": {
        "x": 10.0,
        "y": 20.0,
        "w": 50.0,
        "h": 8.0
      },
      "content": "빠르게 지나친 문장"
    }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 정상 큐 반환 완료 |
| 404 | {errorCode: DOC_04, message: 요청하신 문서를 찾을 수 없습니다.} |
