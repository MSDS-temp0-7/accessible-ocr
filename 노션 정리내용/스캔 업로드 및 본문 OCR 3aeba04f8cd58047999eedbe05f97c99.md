# 스캔 업로드 및 본문 OCR

카테고리: 코어 인식 파이프라인
설명: 스캔 이미지를 업로드하여 본문 OCR 텍스트화 및 콘텐츠 유형(표/그래프/수식/악보)을 자동 분류함.
Method: POST
URL: /api/v1/documents/ocr
param: file  (Multipart)
기타: 본문 인식률 98~99% 기준 준수.
사용자: 검수자

### Request

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `file` | OCR 및 분류를 진행할 스캔 원본 이미지 | `File` | .pdf, .jpg, .png | N | `(Binary Data)` |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `documentId` | 처리된 문서의 고유 ID | `String` |  | N | `doc_ocr_123` |
| `status` | 처리 상태 | `String` | CLASSIFIED, PROCESSING | N | `CLASSIFIED` |
| `blocks` | 인식 및 분류가 완료된 콘텐츠 블록 배열 | `Array` | 본문 우선 정렬 | N | `[{...}]` |
| `blocks[].blockId` | 분류된 블록 고유 ID | `String` |  | N | `blk_01` |
| `blocks[].type` | 콘텐츠 유형 | `String` | TEXT, TABLE, GRAPH, MATH, MUSIC | N | `TEXT` |
| `blocks[].content` | 텍스트화된 본문 내용 (TEXT 타입인 경우) | `String` | 본문 인식률 98~99% 기준 적용 | Y | `인식된 본문입니다.` |

**Example**

```jsx
{
  "documentId": "doc_ocr_123",
  "status": "CLASSIFIED",
  "blocks": [
    {
      "blockId": "blk_01",
      "type": "TEXT",
      "content": "인식된 본문입니다."
    },
    {
      "blockId": "blk_02",
      "type": "TABLE",
      "content": null
    },
    {
      "blockId": "blk_03",
      "type": "MATH",
      "content": null
    }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 201 | 정상 업로드 및 OCR/분류 처리 완료 |
| 400 | {errorCode: REQ_03, message: 스캔 이미지를 판독할 수 없거나 지원하지 않는 파일 형식입니다.} |
| 401 | {errorCode: AUTH_01, message: 로그인이 필요합니다.} |
| 403 | {errorCode: AUTH_03, message: 검수자 권한이 필요합니다.} |
