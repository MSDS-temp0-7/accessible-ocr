# 다운로드링크조회

카테고리: 산출물 내보내기
설명: 변환이 완료된 파일의 실제 다운로드 URL(예: S3 링크)을 가져옵니다.
Method: GET
URL: /documents/{id}/download
param: id (Path)
사용자: 공통

### **Query parameter**

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `id` | 다운로드할 문서의 고유 ID (Path) | `String` |  | N | `"doc_998877"` |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `downloadUrl` | 변환 완료된 파일의 실제 다운로드 링크 (S3 등) | `String` |  | N | `"https://storage.../doc_998877.zip"` |
| `expiresAt` | 링크 만료 일시 | `String` | ISO 8601 포맷 | N | `"2026-08-01T21:00:00Z"` |

**Example**

```jsx
{
  "downloadUrl": "https://storage.example.com/exports/doc_998877.zip",
  "expiresAt": "2026-08-01T21:00:00Z"
}
```

### Status

| status | response content |
| --- | --- |
| status | response content |
| 200 | 정상 링크 조회 완료 |
| 401 | {"errorCode": "AUTH_01", "message": "로그인이 필요합니다."} |
| 404 | {"errorCode": "DOC_05", "message": "변환된 파일이 없거나 아직 준비되지 않았습니다."} |
