# 채류시간기록

카테고리: 편집 및 검수
설명: 해당 구간에 커서가 머문 체류시간을 전송하여 재검토 큐(F9)에 활용합니다
Method: POST
URL: /documents/{id}/blocks/{blockId}/focus
param: durationMs
사용자: 검수자

### Request

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `durationMs` | 해당 구간에 커서가 머문 시간(밀리초) | `Integer` |  | N | `1500` |

### **Query parameter**

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| `id` | 문서 고유 ID (Path) | `String` |  | N | `"doc_998877"` |
| `blockId` | 체류시간을 기록할 블록의 고유 ID (Path) | `String` |  | N | `"blk_001"` |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `success` | 기록 성공 여부 | `Boolean` |  | N | `true` |
| `needsReview` | 재검토 큐(F9) 편입 여부 | `Boolean` | 백엔드 로직 판단 결과 반환 | N | `true` |

**Example**

```jsx
{
  "success": true,
  "needsReview": true
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 체류시간 정상 기록 완료 |
| 401 | {errorCode: AUTH_01, message: 로그인이 필요합니다.} |
| 404 | {errorCode: DOC_04, message: 요청하신 블록을 찾을 수 없습니다.} |
