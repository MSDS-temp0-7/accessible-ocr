# 내 할당 큐 조회

카테고리: 유저
설명: 자원봉사자 본인에게 배정된 비동기 검수 대상 문서 목록을 봅니다 (Step V1).
Method: GET
URL: /user/me/queue
param: -
사용자: 검수자

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `assignedQueue` | 봉사자에게 배정된 문서 배열 | `Array` |  | N | `[{...}]` |
| `assignedQueue[].documentId` | 문서 고유 ID | `String` |  | N | `doc_445566` |
| `assignedQueue[].title` | 문서 제목 (개인 문서) | `String` |  | N | `요청_자료_1.pdf` |
| `assignedQueue[].assignedAt` | 배정된 일시 | `String` | ISO 8601 포맷 | N | `2026-07-31T16:00:00Z` |
| `assignedQueue[].progress` | 검수 진행률 | `Integer` | 0 ~ 100 (%) | N | `15` |

**Example**

```jsx
{
  "assignedQueue": [
    {
      "documentId": "doc_445566",
      "title": "요청_자료_1.pdf",
      "assignedAt": "2026-07-31T16:00:00Z",
      "progress": 15
    }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 정상 조회 완료 |
| 401 | {errorCode: AUTH_01, message: 토큰이 만료되었습니다.} |
| 403 | {errorCode: AUTH_03, message: 검수자(자원봉사자) 권한이 없습니다.} |
