# 저신뢰 구간 검색

카테고리: 검색
설명: 특정 문서 내에서 AI 신뢰도가 낮은(예: 0.5 미만) 구간만 모아서 큐를 반환합니다 (F8).  
Method: GET
URL: /search/blocks/low-confidence
param: documentId, threshold
사용자: 검수자

### **Query parameter**

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `documentId` | 검색할 대상 문서 ID | `String` |  | N | `"doc_12345"` |
| `threshold` | 저신뢰 기준 점수 (기본값: 0.5) | `Float` | 0.0 ~ 1.0 | Y | `0.5` |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| `queue` | 저신뢰 구간 블록 배열 (F8 큐) | `Array` | 신뢰도 오름차순 정렬 | N | `[{...}]` |
| `queue[].blockId` | 블록 고유 ID | `String` |  | N | `"blk_01"` |
| `queue[].pageNumber` | 해당 블록이 위치한 페이지 | `Integer` |  | N | `12` |
| `queue[].confidence` | AI 신뢰도 점수 | `Float` | threshold 이하의 값 | N | `0.32` |
| `queue[].bbox` | 영역 좌표 | `Object` | 백분율(%) | N | `{"x":10.5...}` |
| `queue[].content` | 인식된 텍스트 초안 | `String` |  | N | `"잘못 인식된 글자"` |

**Example**

```jsx
{
  "queue": [
    {
      "blockId": "blk_01",
      "pageNumber": 12,
      "confidence": 0.32,
      "bbox": {
        "x": 45.0,
        "y": 60.5,
        "w": 30.0,
        "h": 5.0
      },
      "content": "잘못 인식된 글자"
    }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 정상 큐 반환 완료 |
| 400 | {"errorCode": "REQ_01", "message": "잘못된 파라미터(threshold 범위 초과 등)입니다."} |
| 404 | {"errorCode": "DOC_04", "message": "요청하신 문서를 찾을 수 없습니다."} |
